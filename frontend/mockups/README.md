# Макет оформления «Угли» (design reference)

Выбранная тема внешнего вида фронтенда: тёмная палитра с огненно-оранжевым
акцентом. Этот каталог — **статичный макет-ориентир**, а не каркас приложения:
реальный фронтенд (React + Vite, Ant Design, TanStack Query, React Router, npm)
живёт в `frontend/` и реализует ту же палитру через токены AntD и CSS-переменные.

## Как смотреть

Откройте `frontend/mockups/index.html` (или сразу `themes/embers.html`) двойным
кликом — страницы работают с диска (`file://`). Дополнительные виды открываются
параметрами URL: `?page=log`, `?page=stats`, `?portal=<id>` (карточка портала с
действиями), например `themes/embers.html?page=log&portal=1`.

Макет требует доступа в интернет: Ant Design и иконки подключаются по CDN
(jsdelivr), чтобы не тащить зависимости в мок.

## Палитра

| Роль | Значение |
| --- | --- |
| Акцент (primary) | `#ff6a00` |
| Фон страницы | `#0e0905` |
| Контейнеры (карточки, таблицы) | `#171008` |
| Поверхности (модалки, меню) | `#1e1409` |
| Боковая панель | `linear-gradient(180deg, #150d05, #0a0603)` |
| Шапка | `#120b07` |
| Полоса сверху | `linear-gradient(90deg, #ff4d00, #ff8c00, #ffc46b)` |
| Логотип | `linear-gradient(135deg, #ffad33, #ff4d00)` |
| Индикатор Live | `#5ee08a` |

Семантические цвета иконок статистики: всего — акцент, открыто — `#52c41a`,
закрыто — `#8c8c8c`, отмечено — `#fa8c16`, с наблюдателем — `#13c2c2`,
средний риск — цвет текущего уровня опасности.

## Что внутри

- `themes/embers.html` — единственная тема: `window.THEME` (акцент, тёмная,
  боковая компоновка) и CSS-переменные оформления.
- `shared/app.compiled.js` — рендерер макета: таблица порталов, модальная
  карточка портала со всеми действиями, журнал действий, статистика. Это
  предкомпилированный plain-JS вариант `shared/app.js` (источник, с JSX).
  Пересобрать: `npm i --no-save @babel/standalone && node build.js`.
- `shared/data.js` — мок-данные. Риск и уровни опасности считаются по формуле из
  бэкенда (`backend/app/models.py`), доступность действий повторяет условия
  `Portal`-методов, но всё это вымышлено.

## Важно

- Код рендерера и классы `mock-*` **не переносятся** в реальное приложение.
- Кнопки в макете имитируют результат действия локально. В приложении действие
  выполняет бэкенд (`POST /portals/{id}`), а состояние приходит WS-снапшотом —
  целиком, без мержа.
