Макет «Угли»

Выбранная тема оформления «Лаборатории порталов»: тёмный интерфейс с огненно-оранжевым акцентом. Макет — статичная страница-ориентир; реальный фронтенд (React + Vite + Ant Design) реализует эту палитру.

Угли

Боковая панель слева, почти чёрный тёплый фон, оранжевый акцент и мягкое свечение логотипа. Карточка портала открывается модальным окном; иконки статистики окрашены по смыслу.

Открыть макет →
Макет собран на Ant Design по CDN и делит рендерер shared/app.compiled.js (plain-JS сборка shared/app.js, пересобрать: node build.js). Страницы открываются прямо с диска (file://). Дополнительные виды — параметрами URL: ?page=log, ?page=stats, ?portal=<id>.
